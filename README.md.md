# HIGH TECH PS 🎮

الموقع الرسمي لـ **HIGH TECH PS** المتخصص في صيانة وتعديل أجهزة PlayStation[cite: 2].

## 🚀 المميزات
* **واجهة العاب عصرية:** تصميم متجاوب وألوان Dark Gaming[cite: 2].
* **زر الختم الذهبي (GOLD HEN):** تصميم تفاعلي خاص بالمركز[cite: 2].
* **تخزين أوفلاين (Cache Support):** إمكانية تحفيظ ملفات الموقع ليعمل بدون اتصال بالإنترنت.
* **دعم شامل للسوفتات والثغرات:**
  * **PS4:** السوفتات من `5.00` حتى `11.02`[cite: 2]
  * **PS5:** السوفتات من `9.00` حتى `13.60`[cite: 2]
  * **الثغرات المدعومة:** Webkit, Jailbreak, GoldHEN, PSFree, Payloads[cite: 2].

## 🛠️ كيفية الرفع على GitHub Pages
1. أنشئ مستودع جديد (Repository) باسم `hightech-ps`[cite: 2].
2. ارفع الملفات التالية للمستودع[cite: 2]:
   * `index.html`[cite: 2]
   * `style.css`[cite: 2]
   * `cache.js`
   * `sw.js`[cite: 2]
   * `README.md`[cite: 2]
3. اذهب إلى **Settings** > **Pages**[cite: 2].
4. اختر الفرع `main` أو `master` ثم اضغط **Save**[cite: 2].
5. رابط موقعك سيكون جاهزاً خلال دقائق![cite: 2]
