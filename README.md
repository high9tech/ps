# HIGH TECH PS 🎮

الموقع الرسمي لـ **HIGH TECH PS** المتخصص في صيانة وتعديل أجهزة PlayStation.

## 🚀 المميزات
* **واجهة العاب عصرية:** تصميم متجاوب وألوان Dark Gaming.
* **زر الختم الذهبي (GOLD HEN):** تصميم تفاعلي خاص بالمركز.
* **دعم شامل للسوفتات والثغرات:**
  * **PS4:** السوفتات من `5.00` حتى `11.02`
  * **PS5:** السوفتات من `9.00` حتى `13.60`
  * **الثغرات المدعومة:** Webkit, Jailbreak, GoldHEN, PSFree, Payloads.

## 🛠️ كيفية الرفع على GitHub Pages
1. أنشئ مستودع جديد (Repository) باسم `hightech-ps`.
2. ارفع الملفات التالية للمستودع:
   * `index.html`
   * `style.css`
   * `sw.js`
   * `README.md`
3. اذهب إلى **Settings** > **Pages**.
4. اختر الفرع `main` أو `master` ثم اضغط **Save**.
5. رابط موقعك سيكون جاهزاً خلال دقائق!
