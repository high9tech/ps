# HIGH TECH PS - Jailbreak Host

هذا المشروع عبارة عن مستودع (Host) مخصص لأجهزة PlayStation، تم تصميمه ليعمل بكفاءة عالية على GitHub Pages، ويدعم التشغيل دون اتصال بالإنترنت (Offline Mode) من خلال ملف الكاش.

## محتويات المشروع
- `index.html`: الواجهة الرئيسية للمستخدم لعرض الحالة واختيار الـ Payloads.
- `script.js`: المحرك البرمجي المسؤول عن محاكاة التعديل وحقن الـ Payloads.
- `cache.manifest`: ملف التخزين المؤقت لضمان عمل الموقع دون الحاجة لاتصال بالإنترنت بعد الزيارة الأولى.

## كيفية التشغيل
1. قم برفع كافة الملفات إلى مستودع جديد على حسابك في GitHub.
2. توجه إلى إعدادات المستودع (Settings) ثم (Pages).
3. اختر الفرع (Branch) الذي يحتوي على الملفات (عادة `main`) واضغط حفظ.
4. بعد تفعيل الصفحات، استخدم الرابط الناتج (مثلاً `https://username.github.io/repo-name/`) وافتحه من متصفح جهاز البلايستيشن.
5. سيقوم المتصفح تلقائياً بحفظ الملفات في الكاش، وبعد ذلك يمكنك استخدامه دون إنترنت.

## ملاحظات
- تم تحسين التصميم ليكون متوافقاً مع شاشات البلايستيشن.
- تم إضافة نظام سجل (Console Log) لمتابعة حالة التعديل لحظة بلحظة.
- تم ضبط ملف الكاش ليعمل مع أي تحديثات مستقبلية.
